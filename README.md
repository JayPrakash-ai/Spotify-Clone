🎵 Spotify Clone

A Spotify-inspired music streaming web interface built using HTML and CSS. This project recreates the look and feel of a modern music streaming platform with a clean layout and dark theme.

✨ Features

- Spotify-inspired user interface
- Dark theme design
- Sidebar navigation
- Music library section
- Playlist interface
- Responsive layout
- Modern styling

🛠️ Tech Stack

- HTML5
- CSS3

📂 Project Structure

Spotify-Clone/
├── index.html
├── style.css
└── README.md

🚀 How to Run

1. Clone this repository:

git clone https://github.com/JayPrakash-ai/Spotify-Clone.git

2. Open the project folder.
3. Open "index.html" in your browser.

🎯 Purpose

This project was built to practice frontend web development, HTML structure, CSS styling, layouts, and recreating a modern website interface.
